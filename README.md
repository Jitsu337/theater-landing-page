# Theater Landing Page

A modern, responsive theater landing page built from scratch.

## Built With

- HTML5
- Tailwind CSS
- JavaScript
- Responsive Design

## Features

- Responsive navigation
- Mobile menu
- Cinematic hero section
- Featured show cards
- Scroll animations
- Smooth scrolling
- Contact form
- Responsive layout

## Project

This project was created as a frontend development portfolio project
to practice building modern, responsive websites with Tailwind CSS
and JavaScript.
